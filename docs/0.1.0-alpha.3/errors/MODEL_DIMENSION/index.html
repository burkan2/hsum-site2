MODEL_DIMENSION

MODEL_INCOMPATIBLE not retryable exit 3

Problem

the local model is incompatible with this index

Cause

its fingerprint or vector dimension differs from the pinned index contract

Fix

use the pinned model or create a new index

Explain this offline

No network required — the same catalog ships inside the binary:

hsum help error MODEL_DIMENSION

Category

MODEL_INCOMPATIBLE — The local model does not match this index's pinned contract.
