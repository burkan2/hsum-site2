QUERY_FINGERPRINT

STALE_CURSOR not retryable exit 1

Problem

the search cursor is stale

Cause

its bound index, generation, scope, or query state changed

Fix

restart pagination without the cursor

Explain this offline

No network required — the same catalog ships inside the binary:

hsum help error QUERY_FINGERPRINT

Category

STALE_CURSOR — A pagination cursor no longer matches current index state.
