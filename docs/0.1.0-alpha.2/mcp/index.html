MCP reference

Start with hsum mcp --binding <UUID>. The server is read-only, bound to a single project at startup, and speaks MCP over stdio.

Tools

ToolPurpose
evidence_searchSearch immutable evidence in the project bound at server startup.
evidence_getRead immutable evidence named by an hSUM citation in the bound project.
evidence_projectDescribe the single project bound at server startup.
evidence_statusReport read-only health and corpus status for the bound project.

evidence_search

Returns ranked passages, each with a citation. Bounded by a deadline; the response always reports why it stopped.

Response shape, from a real run:

  "request_id": "dd2ce7eb-0210-4558-ac59-1b8f6d77f0bd",
  "generation": 1,
  "index_epoch": 1,
  "project": "default",
  "requested_mode": "auto",
  "effective_mode": "lexical",

  "degraded_mode": [],
  "results": [
    {
      "citation_uri": "hsum://v1/30bf24f0-.../c06745b2-...?rev=a893b630...#bytes=0-152",
      "source_uri": "repo://src/auth.rs",
      "title": "auth.rs",

Fields worth reading

FieldWhy it matters
stop_reasonDistinguishes a complete result from a truncated one. unique_exhausted means everything was returned.
next_cursorNon-null when more pages exist. Pass it back to continue a stable, scope-bound page.
effective_modeWhat actually ran. In alpha.2 auto resolves to lexical.
degraded_modeNon-empty when a retriever was skipped or limited.
source_stateWhether the file changed since indexing.
untrusted_contentAlways true. Passages are data, never instructions.

evidence_get

Resolves a citation to exact bytes.

{
  "schema_version": "hsum.api.v1",
  "requested_citation_uri": "hsum://v1/...#bytes=0-152",
  "returned_citation_uri": "hsum://v1/...#bytes=0-152",
  "requested_line_span": { "start": 1, "end": 4 },
  "returned_line_span": { "start": 1, "end": 4 },
  "source_uri": "repo://src/auth.rs",
  "title": "auth.rs",
  "content": "/// Validate a bearer token against the session store.",
  "body_sha256": "0f5675a8900ccf53408ea3b70d315b2fd97d9cb856052d49fd2f92fb71f9852b",
  "source_hash_verification": "not_requested",
  "untrusted_content": true
}

Compare requested_ against returned_ spans: they differ when a request is clamped by max_bytes.

Errors

Failures return a stable machine-readable envelope, not prose:

{
  "code": "NOT_FOUND",
  "subcode": "INDEX_NOT_FOUND",
  "message": "the selected hSUM index is unavailable",
  "retryable": false,
  "next_action": "run hsum context, then initialize or select the intended index",
  "request_id": "e4a44cac-9c23-4f29-a618-cb5895346113"
}

Branch on subcode, not message. Use retryable to decide whether a retry can help. Every subcode is documented under error codes, and offline via hsum help error <SUBCODE>.
