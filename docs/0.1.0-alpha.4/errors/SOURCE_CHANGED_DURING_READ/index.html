SOURCE_CHANGED_DURING_READ

SOURCE_INVALID retryable exit 1

Problem

a source file changed while it was read

Cause

two stable descriptor reads could not capture one snapshot

Fix

retry after the writer becomes idle

Explain this offline

No network required — the same catalog ships inside the binary:

hsum help error SOURCE_CHANGED_DURING_READ

Category

SOURCE_INVALID — A source file could not be ingested as valid text.
