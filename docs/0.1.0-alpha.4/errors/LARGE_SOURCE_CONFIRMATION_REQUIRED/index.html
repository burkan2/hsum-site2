LARGE_SOURCE_CONFIRMATION_REQUIRED

INVALID_ARGUMENT not retryable exit 2

Problem

the selected source exceeds the default initialization budget

Cause

the estimated file count or byte total requires an explicit large-source decision

Fix

inspect the estimate, then repeat with --allow-large-source if intended

Explain this offline

No network required — the same catalog ships inside the binary:

hsum help error LARGE_SOURCE_CONFIRMATION_REQUIRED

Category

INVALID_ARGUMENT — The request was rejected before any work began — an input broke a documented contract.
